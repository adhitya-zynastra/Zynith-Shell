# Getting help

- **Using Zynith**: the user guide, [`docs/user/`](docs/user/), covers using, configuring and troubleshooting
  Zynith; [The ISO](docs/development/iso.md) covers installing it.
- **Building and developing**: [`docs/`](docs/), starting with
  [Building and running](docs/development/building.md). Its [Recovery](docs/development/building.md#recovery)
  section covers a desktop that does not come up.
- **Bugs and feature requests**: the issue tracker of this repository. Search existing issues first, and use the
  templates. For a bug, say which Zynith version (`zynith-ui status`) and Fedora version you run, and attach the logs
  (`zynith-ui log`, `journalctl --user -b`).
- **Security problems**: not in public issues. See [SECURITY](SECURITY.md).

Zynith is a volunteer project; there is no guaranteed response time.
